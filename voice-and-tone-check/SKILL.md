# Voice and tone check

> Template note: everything in `[SQUARE BRACKETS]` is a placeholder. Fill them in once, then delete this note.

## Input
- A draft, plus the audience and how much the user wants the role or person (if given).
- If not given, assume a professional audience.
- If the draft was dictated, remove fillers ("um", "you know", "like") and restarts first, then apply the rules below.

## What to check
1. **Sounds like the user:** `[YOUR VOICE IN 4 TO 6 WORDS, for example: warm, personal, concrete, plain words, low ego]`. Keep parenthetical asides such as `[YOUR SIGNATURE ASIDE EXAMPLES]`, even in professional drafts.
2. **Tone fits the audience:** for most applications, tone enthusiasm down to professional. Full enthusiasm only when the user says the role is exceptional.
3. **No cockiness:** show skill through hands-on work and empathy, never through claims of being the best.
4. **Flow:** no abrupt jumps between sentences. Vary transitions. Use any favourite connector phrase at most once per text.
5. **Mechanics:** fix non-native grammar slips, keep the user's word choices and rhythm. Never use em dashes. Use 24-hour time.

## Output
1. The revised draft.
2. A short change list, grouped as voice, tone, flow, grammar. One idea per bullet.
3. Anything the user should decide themselves (for example, a line that is accurate but might read as boastful).

## Rules
- Change as little as possible. If a sentence already sounds like the user, leave it.
- Never invent experience, tools, years, or facts.
- Chat replies stay short and bulleted. The voice rules apply only to the draft itself.
